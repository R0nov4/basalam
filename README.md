## ⚠️ سلب مسئولیت

این مخزن فقط برای **اهداف آموزشی و افشای مسئولانه** منتشر شده است. همه تستها فقط روی اکانتهای آزمایشی خودم انجام شده و هیچ دادهی کاربر واقعی جمعآوری یا تخریب نشده است. پیلود فقط `alert(document.domain)` است — چیزی بیشتر از اثبات اجرای کد انجام نمیدهد. اگر باگ قبل از خواندن شما اصلاح شده بود، بخش «لینکهای زنده» منسوخ است و همین یک مدرک کافی است که مشکل وجود داشته است.

## 🧨 خلاصه (TL;DR)

دو باگ مستقل که در کنار هم یک زنجیرهی کامل میسازند:

1. **انتشار محصول از غرفهی هرگز فعال نشده** — غرفهای که `is_active=false` و `status=3748` («درخواست ایجاد غرفه» در انتظار تایید) است، از طریق API عمومی (`openapi.basalam.com`) با `status=2976 (PUBLISHED)` محصول **منتشرشده** میسازد. فعالسازی غرفه فقط در رابط کاربری اعمال میشود، نه در لایهی API.
2. **Stored XSS در بلوک JSON-LD** — فیلد `name` محصول بدون هیچ encode ای مستقیماً داخل `<script type="application/ld+json">` صفحهی عمومی محصول نوشته میشود. کافی است نام محصول این باشد:

```
</script><svg onload=alert(document.domain)>
```

تگ اسکریپت را میبندد و SVG با onload در **مرورگر هر بازدیدکنندهای** اجرا میشود. صفحه **هیچ CSP ای ندارد**.

> 🎯 **پاسخ به سؤال رایج: غرفه باید فعال باشد یا غیرفعال؟**
> **غیرفعال!** این خودش حلقهی اول زنجیره است — اکانت رایگان بساز، غرفه بساز ولی «فعالسازی» نکن (بماند در حالت «در انتظار تایید»). اگر غرفهات فعال هم باشد، باگ XSS بهتنهایی مستقل کار میکند؛ ولی زنجیرهی کامل یعنی: غرفهی غیرفعال + انتشار عمومی.

## ❌ چرا ادعای تریاژ از نظر فنی غلط است

گزارش با این جمله رد شد:

> «آسیبپذیریهای XSS که فقط روی دستگاه مهاجم Render شود.»

این ادعا با دو آزمون مستقل نقض میشود:

**۱) SSR با curl کاملاً ناشناس (بدون کوکی، بدون اکانت):**

```bash
curl -s - https://basalam.com/kai-2026/product/59890692 \
  | grep -c '</script><svg onload=alert(document.domain)>'
```

خروجی: 1  ← پیلود خام داخل HTML سروشده از سرور، برای همه


**۲) مرورگر headless ناشناس** — کانتکست کاملاً جدید، **صفر کوکی، صفر storage، بدون لاگین**:

```text
headless anonymous browser : alert FIRED  message='basalam.com'  type='alert'
svg[onload] in DOM=1  (cookies: none)
```

پیلود از **سرور** به مرورگر هر بازدیدکنندهی ناشناسی میرسد و همانجا اجرا میشود. «دستگاه مهاجم» هیچ نقشی در این قضیه ندارد.

- `https://basalam.com/kai-2026/product/59890692`

